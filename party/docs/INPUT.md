# CPI Input Layer\n\nThe engine exposes logical game actions independently of the device that produced them.\n\n- **InputMap** maps a physical source/code pair to a logical action.\n- **GameInput** is the normalized event games consume.\n- **normalizeInput()** validates optional numeric/vector/button fields.\n- **resolveInput()** lets browser or native adapters translate keyboard, mouse, touch, motion, gamepad, or native controls.\n\nExisting games do not need to migrate immediately. New games such as CPI: Cold Case should define gameplay around logical actions and let platform adapters decide how those actions are triggered.\n\nExample actions can include `MOVE`, `LOOK`, `INTERACT`, `USE_TOOL`, `PRIMARY`, and `SECONDARY`. These are conventions, not a fixed global list; a game may define the actions it needs.
