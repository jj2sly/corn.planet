CPI PARTY DESKTOP — START HERE

GROUP NIGHT
1. Open CPI Party.
2. If the app says SETUP REQUIRED, choose USE PUBLIC SERVER (the public Railway server,
   https://cornplanet-production.up.railway.app), or paste another Party server URL and choose SAVE & CHECK.
3. Wait for GROUP NIGHT READINESS to show:
   - SERVER: ONLINE
   - GAMES: 6 / 6
   - CANON: at least 2 records
   - PROTOCOL: a number
4. Use START GROUP NIGHT for the full-screen host display.
5. Players scan the phone QR or use the copied phone link. The room code fills in by itself; they only
   type an agent name. (Without the QR, they enter the four-letter code shown by the host.)
6. Choose the game from the Party host screen.

IMPORTANT
- Do not close CPI Party while a host display is live. The app warns before closing because doing so can pause an active game.
- If you open another CPI section while hosting, the host display stays connected in the background.
- Use RETURN TO HOST in the Command Center to get back to it.
- STOP HOST DISPLAY intentionally disconnects the host display.

UPDATES
- The Command Center's DESKTOP UPDATE card shows your version and checks GitHub Releases shortly after
  launch and every few hours. CHECK FOR UPDATES checks right away.
- Windows (installed with CPI-Party-Setup): new versions download in the background. When one is
  ready, choose RESTART & UPDATE, or LATER to have it install the next time you quit. It will not
  restart while a Party host is live: stop the host first.
- Windows portable EXE: does not update itself. The card tells you when a new version is out and
  DOWNLOAD UPDATE opens the release page.
- macOS: these builds are not code-signed, so macOS will not let the app replace itself. The card
  tells you when a new version is out and which file your Mac needs; DOWNLOAD UPDATE opens the
  release page. Replace the app in Applications with the new one. Your Party server setting is kept.

MAC DOWNLOADS
- Intel Macs: CPI-Party-<version>-x64.dmg
- Apple silicon Macs (M1 and newer): CPI-Party-<version>-arm64.dmg
  (Apple menu > About This Mac shows "Chip: Apple M…" on Apple silicon, "Processor: Intel" on Intel.)
- First launch of an unsigned build: right-click CPI Party in Applications and choose Open.

LOCAL SERVER
If the Party server is running locally, the desktop app automatically tries to turn localhost into this computer's LAN IP for the phone QR. Phones still need to be able to reach the computer over the same network.

PC GAME
PC Games -> Corn or Shit — Solo
This mode uses keyboard/mouse and live CPI canon. It does not require phones or a room.
